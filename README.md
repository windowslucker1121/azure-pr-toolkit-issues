# Azure Pull Request Toolkit — issues and releases

Review, comment on and create Azure DevOps pull requests without leaving VS Code
This repository is for **bug reports, feature requests and release downloads**

## Install

- **VS Code Marketplace:** search for *Azure Pull Request Toolkit* in the Extensions view
- **Manual:** download the `.vsix` from [Releases](../../releases) and run
  `code --install-extension azure-pr-toolkit-<version>.vsix`

## Report a bug

[Open an issue](../../issues/new) and include:

- the extension version and VS Code version (**Help → About**)
- Azure DevOps Services or Server, and how you signed in (Microsoft account or personal access token)
- steps to reproduce, what you expected and what happened
- relevant lines from the **Azure Pull Request Toolkit** output channel
  (**View → Output**). Remove organization names, URLs or anything else confidential

## Security

Do not report security problems in public issues. Use
[**Security → Report a vulnerability**](../../security/advisories/new) instead
